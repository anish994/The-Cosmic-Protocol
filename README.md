# 🌌 The Cosmic Protocol

> *An immersive cosmic simulation exploring the dance between order and chaos, consciousness and entropy.*

## ✨ Overview

The Cosmic Protocol is an interactive web-based simulation that visualizes the fundamental forces shaping our universe. Experience the eternal interplay between creation and dissolution, structure and randomness, consciousness and void.

## 🎯 Features

- **Real-time Particle System**: Watch thousands of particles interact under cosmic forces
- **Dynamic Force Mechanics**: Experience the balance between Order (attraction) and Chaos (entropy)
- **Interactive Controls**: Adjust fundamental parameters and witness immediate cosmic consequences
- **Immersive Audio**: Ambient soundscape that responds to the simulation state
- **Responsive Design**: Seamless experience across all devices

## 🚀 Quick Start

### Option 1: Direct Browser
Simply open `index.html` in your web browser - no installation required!

### Option 2: Local Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Then visit: http://localhost:8000
```

## 🎮 Controls

- **Order Strength**: Controls the gravitational pull toward cosmic centers
- **Chaos Intensity**: Determines the level of entropic dispersion
- **Particle Count**: Adjusts the density of the cosmic simulation
- **Speed**: Controls the rate of time flow in the simulation
- **Audio Toggle**: Enable/disable ambient cosmic soundscape

## 🛠️ Technologies

- Pure HTML5 Canvas for rendering
- Vanilla JavaScript for particle physics
- CSS3 for stunning visual effects
- Web Audio API for immersive sound
