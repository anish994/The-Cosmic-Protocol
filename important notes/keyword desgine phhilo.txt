




# 🏷️ KEYWORD DESIGN PHILOSOPHY & RULES

## Core Philosophy

### The Three-Layer System

```
┌─────────────────────────────────────────────────┐
│ LAYER 1: ELEMENTS (Environmental/Visual)       │
│ - Fire, Ice, Lightning, Water, etc.            │
│ - Defines: Damage type, visual, environment    │
│ - Creates: Environmental interactions          │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ LAYER 2: KEYWORDS (Mechanical Behavior)        │
│ - DoT, Stun, Shield, Reflect, etc.             │
│ - Defines: Game mechanics, rules, behavior     │
│ - Creates: Tactical interactions               │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ LAYER 3: SKILLS (The Container)                │
│ - Fireball, Barrier Wall, Summon, etc.         │
│ - Defines: Base function, delivery method      │
│ - Creates: Final ability                       │
└─────────────────────────────────────────────────┘
```

---

## Keyword Design Principles

### 1. **Mechanical Purity**
Keywords are **mechanically neutral** - they define HOW something works, not WHAT it looks like.

**Example: "DoT" Keyword**
- ⚙️ **Base Mechanic:** Damage over time (ticks damage each turn)
- 🔥 **+ Fire Element:** Burns (fire DoT)
- ☠️ **+ Poison Element:** Toxic damage (poison DoT)
- 🌑 **+ Dark Element:** Corruption (shadow DoT)
- 🔥×🌑 **+ Shadowflame Fusion:** Cursed burn (lifesteal + corruption DoT)

**What the Keyword Defines:**
- Duration (how many turns)
- Tick rate (damage per turn)
- Stacking rules (additive/multiplicative)
- Cleansability (can it be removed)

**What the Element Defines:**
- Damage type (fire/poison/shadow)
- Visual effect (flames/smoke/darkness)
- Secondary effects (spread/drain/curse)

---

### 2. **Cross-Element Compatibility**
Every keyword must work with **ANY element combination**.

**Example: "Reflect" Keyword**
- ⚙️ **Base:** Bounces attacks back to sender
- 🔥 Fire: Reflected attacks burn
- ❄️ Ice: Reflected attacks freeze
- ⚡ Lightning: Reflected attacks chain to nearby enemies
- 💧 Water: Reflected attacks heal you
- 🔥×⚡ Plasma: Reflected attacks explode AND chain
- ❄️×🌑 Frozen Shadow: Reflected attacks freeze AND curse

---

### 3. **Keyword-to-Keyword Synergy**
Keywords combine with OTHER keywords to create new mechanics (independent of elements).

**Combination Types:**

#### **A. Synergy** (Keywords enhance each other)
- `DoT + Spread` = AoE damage over time
- `Shield + Heal` = Regenerating barrier
- `Stun + Silence` = Total lockdown
- `Mark + Empower` = Focused burst damage

#### **B. Opposition** (Keywords conflict to create new effect)
- `Heal + Decay` = Life Drain (damage enemy to heal self)
- `Haste + Stasis` = Time Paradox (random speed)
- `Shield + Pierce` = Shatter (break through defenses)

#### **C. Catalytic** (One keyword amplifies another)
- `Amplify + Any` = 2x effectiveness
- `Chain + Single-target` = Multi-target
- `Persist + Temporary` = Permanent duration

#### **D. Transformative** (Creates entirely new mechanic)
- `Summon + Invoke` = Divine Avatar
- `Draw + Scry` = Prophetic Vision
- `Sacrifice + Resurrect` = Phoenix Protocol

## Keyword Categories & Roles

### **DAMAGE TYPES** (How damage is delivered)
- `Burn` - Fire DoT
- `Poison` - Escalating toxic DoT
- `Bleed` - Physical DoT that punishes movement
- `Decay` - Reduces max HP and armor
- `Curse` - Persistent negative effect

**Design Rule:** Can stack with each other, amplify with elements

---

### **CONTROL EFFECTS** (Action denial)
- `Stun` - Skip turn
- `Stasis` - Total freeze
- `Silence` - Can't use abilities
- `Root` - Can't move
- `Charm` - Mind control

**Design Rule:** Short duration, boss resistance, diminishing returns

---

### **DEFENSIVE MECHANICS** (Damage prevention)
- `Shield` - Absorb damage
- `Armor` - Reduce physical damage
- `Ward` - Reduce magic damage
- `Evasion` - Dodge attacks
- `Immunity` - Prevent specific effect

**Design Rule:** Stackable but with diminishing returns, can be pierced

---

### **BUFF EFFECTS** (Positive modifiers)
- `Haste` - Speed boost
- `Empower` - Damage boost
- `Fortify` - Defense boost
- `Regenerate` - HP over time
- `Focus` - Accuracy/crit boost

**Design Rule:** Temporary, dispellable, stack additively

---

### **UTILITY MECHANICS** (Support actions)
- `Heal` - Restore HP
- `Cleanse` - Remove debuffs
- `Draw` - Card advantage
- `Scry` - Deck manipulation
- `Sacrifice` - Trade resource for power

**Design Rule:** Reactive, high value, cooldowns

---

### **ADVANCED MECHANICS** (Complex interactions)
- `Invoke` - Ultimate power
- `Summon` - Create minion
- `Transform` - Change form
- `Ritual` - Multi-turn setup
- `Echo` - Repeat previous action

**Design Rule:** High cost, unique effects, game-changing

---

## Smart Combination Rules

### **Rule 1: Damage Stacking**
When multiple DoT keywords combine:
```
DoT1 + DoT2 = Both tick separately (additive)
DoT1 + DoT1 = Stacks up to 5x (escalating)
DoT + Spread = AoE DoT
DoT + Amplify = 2x damage per tick
```

### **Rule 2: Control Layering**
When multiple CC keywords combine:
```
Stun + Silence = Total lockdown (can't do anything)
Stun + Root = Redundant (stun is stronger)
Root + Silence = Tactical lockdown (can attack but not move/cast)
Charm + Any CC = Charm overrides (mind control is absolute)
```

### **Rule 3: Defense Stacking**
When multiple defensive keywords combine:
```
Shield + Shield = Layers (must break all)
Armor + Ward = Full resistance (physical + magic)
Shield + Heal = Regenerating barrier
Immunity + Any = Immunity overrides
```

### **Rule 4: Buff Synergy**
When multiple buff keywords combine:
```
Haste + Empower = Quick Assault (speed + damage)
Fortify + Regenerate = Unkillable Tank
Focus + Empower = Guaranteed Critical
All Buffs = Overcharge (risk of burnout)
```

### **Rule 5: Element-Keyword Amplification**
Elements modify keyword mechanics:
```
Fire + DoT = Burn (spread on kill)
Ice + Control = Extended duration
Lightning + Any = Chain to nearby targets
Water + Heal = 2x effectiveness
Earth + Defense = Unbreakable
Dark + Damage = Lifesteal
Light + Buff = Double duration
Void + Any = Ignore resistance
```

## Keyword Evolution System (Tier I/II/III)

### **Tier I (Base Effect)**
- Single-target, standard duration, normal power
- Example: `Burn` deals 10 damage/turn for 3 turns

### **Tier II (Enhanced Effect)**
- Multi-target OR longer duration OR higher power
- Example: `Burn` spreads to 1 adjacent enemy

### **Tier III (Ultimate Effect)**
- All enhancements + unique mechanic
- Example: `Burn` becomes Eternal Flame (never expires, spreads on any damage)

**Evolution Triggers:**
- 3+ of same keyword = Auto-upgrade to Tier II
- 5+ of same keyword = Auto-upgrade to Tier III
- 2+ keyword combos = Unlock Tier II interactions
- 3+ keyword combos = Unlock Tier III fusions

### Example 5: Defensive Skill

## Implementation Strategy

### Phase 1: Define Core Keywords (30-50)
Focus on essential mechanics:
- 5 Damage types
- 5 Control effects
- 5 Defensive mechanics
- 5 Buff effects
- 5 Utility actions
- 5 Advanced mechanics

### Phase 2: Create Combination Rules (50-100)
Map common interactions:
- Same-category synergies (DoT + DoT)
- Cross-category combos (DoT + Control)
- Opposition effects (Heal + Decay)
- Paradox creation (Haste + Stasis)

### Phase 3: Element Integration (12 elements × keywords)
Define how each element modifies keywords:
- Fire: Spread, escalate, area denial
- Ice: Slow, freeze, shatter
- Lightning: Chain, speed, multi-hit
- Water: Heal, flow, cleanse
- Earth: Tank, immovable, persistent
- Dark: Curse, drain, corrupt
- Light: Purify, empower, reveal
- Wind: Mobility, evasion, scatter
- Metal: Pierce, conduct, unbreakable
- Void: Nullify, consume, ignore
- Chaos: Random, wild, unpredictable
- Order: Perfect, guaranteed, controlled

### Phase 4: Tier Evolution System
Implement scaling:
- Tier I = 1 keyword
- Tier II = 2-3 keywords OR elemental fusion
- Tier III = 4+ keywords AND elemental fusion

### Phase 5: AI Learning System (Future)
Dynamic combination discovery:
- Track player combinations
- Detect effective synergies
- Suggest unexplored combos
- Generate new interactions

You're asking a great foundational question about how skills, elements, and keywords interact to create cards (abilities) in your game system. Let's clarify the architecture and the path forward:

1. Core Concepts
Skills: The atomic actions or passives, each with unique mechanics (damage, heal, buff, etc.).
Elements: Modifiers that change how a skill behaves (e.g., Fire adds burn, Water adds cleanse).
Keywords: Tags that further modify or define a skill's properties (e.g., "AoE", "DoT", "Stun").
2. How Cards Are Created
Cards = Skills + (Element Mod) + (Keyword Mod)
You fuse skills into slots to create a card.
Each card is a unique combination of:
The base skill (e.g., "Strike")
An element (e.g., "Fire" → "Fire Strike")
One or more keywords (e.g., "AoE", "Burn" → "Fire Strike AoE Burn")
3. How Elements & Keywords Work Together
Elements act as primary modifiers (change damage type, add elemental effects, alter strengths/weaknesses).
Keywords act as secondary modifiers (add mechanics, status effects, targeting rules, etc.).
When you combine them:
The element may amplify or weaken certain keywords (see your ELEMENT_KEYWORD_MATRIX).
Some element + keyword combos trigger special transformations or synergies (e.g., "Fire + DoT" = "Burn", "Ice + Stun" = "Freeze").
The skill engine reads the base skill, applies the element mod, then applies keyword mods, and finally checks for any special fusion rules.
4. How to Build the Network
Skills reference their possible elements and keywords.
Elements have a matrix of how they interact with keywords (amplify, weaken, transform).
Keywords can be stacked, layered, or fused for advanced effects.
Fusion Engine: When building a card, you run the selected skill through the element and keyword engines, applying all relevant rules and transformations.
5. How to Connect Keywords & Elements Across HTMLs
Elemental Engine (elements.html): Handles element selection, fusion, and amplification logic.
Keyword Engine (keywords.html): Handles keyword selection, fusion, and synergy logic.
Card Builder (future): Will combine both, letting you select a skill, then apply element and keyword mods, showing the final card output.
Data Sharing: Use a shared state (localStorage, or a JS object if on the same page) so both engines can read/write the current selection.

6. Next Steps
Unify the fusion logic: Instead of separate workshops, create a single "Card Builder" UI that lets you pick a skill, then add elements and keywords, and see the result.
Modularize the engines: Make sure both element and keyword engines expose functions for modification and fusion.
Network the rules: When a card is built, run it through both engines, applying all synergy, opposition, catalytic, and transformative rules.
Summary:
Skills are the base. Elements and keywords are mods. Cards are the result of fusing these together, with all engines working in sequence. The network is built by having each engine apply its rules, and by sharing state/data between them.
