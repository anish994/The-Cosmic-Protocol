### Nexus Gate (Central Hub) REGION_SPEC

The Nexus Gate is the architect-forged constant: a compact, layered palace-hub suspended across all parallel timelines. It is intentionally smaller in spatial sprawl than major regions; depth comes from layered functions (arrival, recovery, routing, synthesis) rather than raw area count. It remains stable while realities fracture, providing a unified anchor for resurrection, coordination, skill refinement, and cross-region traversal.

Design Principles:
- Simplicity of layout; depth via interactive subsystems (CPS checkpoint lattice, Resonance relay, Skill infusion alcoves).
- Low baseline danger_tier; escalation only on anomaly/surge/hidden branch.
- Explicit corruption gating: any corruption mention must specify restricted surge/hidden context; ordinary hub play is safe.
- Harmonized resonance bands Echoes + Pulse shape arrival, linking, and timing cycles.

Canonical Tones:
- awe, mysterious, harmonic (secondary: reflective, steady)

Canonical Resonances:
- Echoes (multiversal imprint relay)
- Pulse (timed traversal gate rhythm)

Allowed creature_tier (danger_tier):
- Low (Medium only on scripted surge event; document if used)

Primary Functions:
- Arrival/Spawn Anchor: first stable node; player state normalization.
- CPS Checkpoint Grid: lightweight shard record of skills, karma, and echo imprint; governs resurrection.
- Traversal Router: calibrated links to Architect Domains, Outer Ring, Pantheon Hall, Skill Chamber.
- Skill Infusion: apply Renewal/Echoes derived refinements without full Fusion Chamber risk.
- Memory Echo Board: curated, safe replay of sanitized memory fragments (no raw corruption bleed).

Environmental Logic:
- Stable harmonic field; resonance oscillates in predictable cycles (Pulse windows) enabling fast travel selection.
- Echo damping prevents uncontrolled recursion loops; Paradox signatures are filtered unless a loop key is held.
- Surge Event (rare): “Cross-Reality Alignment” temporarily raises danger_tier to Medium; unlocks hidden transfer paths. All hostile mentions must gate with “(only during alignment surge/hidden branch)”.

Corruption Policy (Low-Corruption Hub):
- Standard state: No ambient corruption.
- Allowed only under: Alignment Surge OR Hidden Architect Override route.
- Wording standard for any node with potential corruption: “None by default; any corruption appears only on alignment surge or hidden override (gated surge/hidden).”

Factions & Presence:
- Ashram Remnants: custodians, maintain harmonic integrity, guide new arrivals.
- Nomadic Relic Seekers: transient advisors, trade sanitized fragments, never destabilize core.
- Rogue AI Fragments: blocked by filters; may flicker as harmless ghost processes unless surge unlocks deeper packet traces.
- Architect Echoes: passive, non-hostile spectral advisors.

Subsystems Overview:
1. Resonance Relay Core: Maintains Echoes <-> Pulse cycle; players can tune for travel priority vs skill cooldown recovery.
2. Checkpoint Pillars (CPS): Lightweight shard log (skill unlock state, karmic adjustments, last safe timeline index). Mutation only at safe pulses; ensures rollback integrity.
3. Skill Infusion Alcoves: Micro-fusion slots allowing Renewal/Echo overlay upgrades without high-tier risk.
4. Memory Echo Board: Browse curated fragments; selecting deep memory routes the player toward Architect Graves or CPS Memory Zones with safety buffer.
5. Traversal Gate Array: Four calibrated arches (Pantheon, Skill Chamber, Outer Ring, Architect Domain) with dynamic cost modulation based on recent actions (karma resonance and echo stability).

Failure / Edge Cases:
- Pulse Desynchronization: Travel options temporarily limited; players can perform a Pulse Recalibration interaction (non-hostile puzzle) instead of combat.
- Surge Overload: If alignment surge active, optional Medium-tier anomaly spawns (echo wraith constructs) must include gating phrase.
- Checkpoint Fragmentation: Hidden branch risk—if taken intentionally, player can access experimental timelines (document deviation in node lore).

Subregion Deep Profiles (Compact Set):

	- Tone: awe, harmonic
	- Resonance: Echoes primary, Pulse secondary
	- Purpose: Normalize player state; first CPS imprint.
	- Interactive: Pulse Calibration (choose rhythm bonus), Echo Sync (align inventory memory tags).
	- Faction Presence: Ashram Remnants greet; Relic Seekers occasionally offer starter fragment (karma-neutral).
	- Danger: Low; no combat unless alignment surge (gated surge/hidden).

2. Resonance Relay Core
	- Tone: mysterious, harmonic
	- Resonance: Pulse primary, Echoes supporting
	- Purpose: Adjust travel latency, skill cooldown shaping.
	- Mechanic: Players allocate resonance charges between “Swift Gate” (fast traversal) or “Safe Imprint” (enhanced checkpoint fidelity).
	- Edge: Over-allocation triggers minor desync anomaly (gated surge) revealing hidden optimization node.

3. Skill Infusion Alcoves
	- Tone: reflective, harmonic
	- Resonance: Echoes + Renewal (Renewal is capped; appears only as supportive tag, not region canonical)
	- Purpose: Craft incremental refinements; low-risk infusion loops.
	- Mechanic: Choose infusion schema: Efficiency (reduce cost), Harmony (improve multi-tag synergy), Resilience (rollback protection).
	- Danger: Low; corruption never unless hidden override (gated surge/hidden).

4. Memory Echo Board
	- Tone: awe, mysterious
	- Resonance: Echoes + Memory (Memory appears only in curated fragment context; not altering base spec)
	- Purpose: Browse sanitized memory sequences; unlock lore travel options.
	- Mechanic: Selecting deeper fragment spawns “Echo Reflection” non-hostile projection offering skill insight.
	- Risk: If player forces raw fragment (hidden override), minor anomaly spawn (gated surge/hidden).

5. Traversal Gate Array
	- Tone: harmonic, mysterious
	- Resonance: Pulse primary; Echoes timing feedback
	- Purpose: Route to external regions; cost scaling based on recent karma variance.

Node Authoring Guidelines (Hub Set 250–259):

- tone_tags subset of [awe, mysterious, harmonic, reflective].
- resonance: [Echoes, Pulse] (plus optional supportive Renewal/Memory only if justified and noted “supportive only”).
- danger_tier: Low.
- Enemy/Corruption Interactions line standard if any hazard: “None by default; any corruption appears only on alignment surge or hidden override (gated surge/hidden).”
- Deviations (Medium) require explicit surge justification line.

Exit / Linking Logic:
- Each hub node should provide at least one outbound link referencing a major region entrance token (e.g., menagerie_entry, eclipse_nexus_entry) enabling narrative continuity.

Performance & Economy:
- Fast iteration focus: minimal spawn scripts, high reuse of shared harmonic descriptors.
- Hub nodes avoid heavy enemy enumeration; emphasize systemic interactions.

Balance Considerations:
- Maintain player safety to encourage experimentation.
- Gated anomalies provide opt-in challenge without undermining hub sanctity.

Lore Hook Summary:
