## 💎 RESOURCE SYSTEM — UNIFIED SCHEMA

### Primary Resource: **Bandwidth**

**Concept:** Operational capacity - enables multiple actions, state transitions, protocol execution  
**Range:** 0-150 typical (soft cap at 100, can exceed with specific skills)  
**Generation:** +10 per turn baseline, +5-20 from skills, structures, states  
**Purpose:** Currency for state transitions, protocol activation, multi-engine support

**Legacy Mapping:**
```
Skill List v3.1    →    Schema v4.0
────────────────────────────────────
Bandwidth          →    Bandwidth (0-150)
Gnosis             →    KP + Bandwidth (cost split)
Coherence          →    Coherence (0-30, secondary resource)
```

**Key Resource Interactions:**
- **Bandwidth:** Spent to enter Neural States, activate Protocols, support multi-engine plays
- **Coherence:** Accumulates 0-30, provides scaling bonuses (+1% all effects per point)
- **Neural States:** Active state determines abilities available and modifiers active
- **Protocols:** Permanent/temporary upgrades costing Bandwidth for powerful effects

### Secondary Resource: **Coherence**

**Concept:** System alignment and optimization level  
**Range:** 0-30 (soft cap at 20, expandable with specific skills)  
**Effect:** +1% ALL effects per Coherence point (linear scaling)  
**Generation:** Gained through state transitions, spending Bandwidth, perfect optimization

**Coherence Thresholds (Milestone Bonuses)**
- **10 Coherence:** +10% all effects, unlock Tier 2 Protocols
- **20 Coherence:** +20% all effects, unlock Tier 3 Protocols
- **30 Coherence:** +30% all effects, unlock Peak Performance states

**Bandwidth Economy**
- **Starting Bandwidth:** 30 (standard)
- **Max Bandwidth:** 100 baseline (expandable to 150 with skills)
- **Generation:** +10/turn baseline, +10 per [Structure], +5 per state transition
- **Spending:** 15-90 per Neural State, 20-150 per Peak Performance state
