## 💎 RESOURCE SYSTEM — UNIFIED SCHEMA

### Primary Resource: **Insight**

**Concept:** Information accumulation - tracks knowledge gained about opponent  
**Range:** 0-100 typical (soft cap at 80, can exceed with specific skills)  
**Generation:** +5 per turn baseline, +10 when opponent uses glyph, +20 from [Reveal] effects  
**Purpose:** Currency for prediction, analysis, and counter-play abilities

**Legacy Mapping:**
```
Skill List v3.1    →    Schema v4.0
────────────────────────────────────
Insight            →    Insight (0-100)
Analysis Points    →    KP + Insight (cost split)
Foresight          →    Foresight (0-50, secondary resource)
```

**Key Resource Interactions:**
- **Insight:** Spent to activate [Reveal], [Forecast], [Profile] glyphs
- **Foresight:** Accumulates 0-50, enables prediction of opponent's next 1-3 turns
- **Knowledge Bank:** Permanent record of opponent's patterns (persists entire match)
- **Counter Tokens:** Generated by successful predictions, spent on [Counter] effects

### Secondary Resource: **Foresight**

**Concept:** Predictive power - enables seeing opponent's future actions  
**Range:** 0-50 (soft cap at 30, expandable with specific skills)  
**Effect:** Each 10 Foresight = predict 1 turn ahead (30 Foresight = see 3 turns ahead)  
**Generation:** Gained through [Forecast] glyphs, successful predictions, opponent repetition

**Foresight Thresholds (Prediction Depth)**
- **10 Foresight:** Predict opponent's next glyph (1 turn ahead)
- **20 Foresight:** Predict opponent's next 2 glyphs (2 turns ahead)
- **30 Foresight:** Predict opponent's next 3 glyphs (3 turns ahead)
- **40+ Foresight:** Predict entire round outcome with 70% accuracy

**Insight Economy**
- **Starting Insight:** 20 (standard)
- **Max Insight:** 80 baseline (expandable to 100 with skills)
- **Generation:** +5/turn baseline, +10 per opponent glyph used, +20 per [Reveal]
- **Spending:** 10-60 per [Reveal]/[Forecast]/[Profile], 20-100 per [Counter]

## 🏷️ CANONICAL KEYWORD FRAMEWORK

### Core Action Keywords

**[Reveal]** - Information extraction
```
Exposes hidden information about opponent
Duration: Permanent (knowledge persists)
Effect: See opponent's glyphs, resources, or strategy
Mercury: [Reveal] costs -2 Insight
Stacks: Multiple [Reveal]s expose different layers
```

**[Forecast]** - Future prediction
```
Predicts opponent's next action(s)
Accuracy: 70-100% depending on Foresight level
Duration: Until prediction resolves (1-3 turns)
Jupiter: [Forecast] accuracy +20%
Generates Foresight on successful prediction
```

**[Insight]** - Pattern recognition
```
Analyzes opponent's past actions for patterns
Effect: Gains Insight resource, identifies tendencies
Duration: Permanent (patterns stored in Knowledge Bank)
Ketu: [Insight] reveals hidden connections
Consciousness signature when combined with [Cohere]
```

**[Profile]** - Strategic analysis
```
Identifies opponent's archetype and win condition
Effect: Reveals opponent's primary strategy (Aggro/Control/Combo/Ramp)
Duration: Permanent (profile persists entire match)
Mercury: [Profile] also reveals secondary strategy
Critical for counter-play decision making
```

**[Counter]** - Reactive negation
```
Negates or punishes opponent's action
Requires: Prior knowledge (Insight, Foresight, or Profile)
Cost: Insight + Counter Tokens
Effect: Cancel glyph, reduce damage, or reflect effect
Must be declared before opponent's action resolves
```

### Information State Keywords

**[Exposed]** - Opponent vulnerability
```
Applied when opponent's information is revealed
Duration: 3 turns (until opponent adapts)
```

**[Analyzed]** - Pattern locked
```
Applied when opponent's patterns identified
Duration: Permanent (until opponent changes strategy)

Mercury: [Analyzed] also reveals resource states
```

**[Predicted]** - Future known
```

Duration: Until prediction resolves (1-3 turns)
```
