## 🏷️ CANONICAL KEYWORD FRAMEWORK

### Core Debuff Keywords

**[Burn]** - Damage over time (fire/energy)
```
Deals X damage per turn
Duration: 3-5 turns typically
Stacks: Up to 10 (increases total damage/turn)
Mars: +10% damage per Burn stack
Detonation: Can be consumed for burst damage
```

**[Decay]** - Entropy amplifier (vulnerability marker)
```
Marks target for entropy/detonation
Duration: Permanent until consumed
Stacks: Up to 10 (increases detonation multiplier)
Detonation Formula: Base damage × (1 + 0.10 × stacks)
Mars Tier 2+: +15% detonation multiplier per stack
```

**[Subservience]** - Control accumulation (puppet strings)
```
Marks target for mind control
Duration: Until consumed or 5 turns
Stacks: 0-10 (at 10 stacks, can fully control for 1 turn)
Consume Effect: Convert to temporary [Control] or redirect actions
Saturn: +1 turn duration per stack
```

**[Stasis]** - Tempo slowdown (temporal lockdown)
```
Reduces action speed, increases costs
Effect: Actions cost +1 Prana per stack
Duration: 3 turns baseline
Stacks: Up to 5 (Saturn can increase cap to 6)
Saturn Tier 3+: +1 stack cap
```

**[Discord]** - Buff corruption (chaotic interference)
```
Weakens enemy buffs, causes action failures
Effect: -10% buff potency per stack, +5% action failure chance
Duration: 4 turns baseline
Stacks: Up to 10
Rahu: +5% additional failure chance per stack
```

**[Void]** - Resource denial (nothingness)
```
Blocks resource generation and effects
Effect: -1 resource generation per stack
Duration: Until consumed for [Banish]
Stacks: Up to 5
12th House: +1 turn duration for all [Void] effects
```

### Core Action Keywords

**[Consume]** - Convert debuff stacks for immediate effect
```
Removes stacks from target
Effect varies by debuff type:
  - [Burn]: Gain Prana
  - [Decay]: Deal burst damage
  - [Subservience]: Control/redirect actions
  - [Void]: Enable [Banish]
Resource Refund: 1-3 Prana typically
```

**[Detonate]** - Explosive detonation of stacks
```
Consumes [Decay] stacks for AoE burst
Damage Formula: Base × (1 + 0.10 × stacks)
Jupiter: +1 AoE radius on even turns
Mars Tier 3+: +15% multiplier per stack
Can trigger chain reactions with multiple debuff types
```

**[Banish]** - Remove target from play temporarily
```
Requires [Void] stacks to activate
Duration: 2-3 turns typically
Effect: Target cannot act or be targeted
Countered by: Winning before return, [Cleanse]
12th House Level 5+: +1 turn duration
```

**[Silence]** - Prevent ability usage
```
Target cannot cast spells/abilities
Duration: 1-2 turns typically
Does not prevent basic actions
Stambhan synergy: [Stasis] enables [Silence] windows
```
