## 🏷️ CANONICAL KEYWORD FRAMEWORK

### Core Action Keywords

**[Omen]** - Tagged draw with conditional bonus
```
Applied to next draw
+30% potency if condition met (revealed enemy action, [Mark] present, etc.)
Duration: Until drawn or replaced
Moon: Creates additional omen simultaneously
```

**[Scry X]** - Reorder/trim top X cards of deck
```
Standard Scry: View top 2-3 cards, reorder or bottom
Deep Scry: View top 5+ cards (Moon bonus)
Effect: Curate draws, avoid bricks, set up omens
Moon Tier 1+: +1 scry depth permanently
```

**[Foretell X]** - Create delayed discounted copy
```
Cost Discount: -30-50% resource cost
Delay: 1-2 turns typically (Mercury reduces to 0 delay)
Effect: Bank future value, dodge disruption windows
Mercury Tier 2+: Foretell results cost -1 KP (once/turn)
```

**[Seal]** - Protect next effect from counter/cancel
```
Single-use protection
Stacks: Can apply multiple seals for multi-layer protection
Duration: Until consumed or turn ends
Divination signature mechanic
```

**[Reveal]** - Force hidden information visible
```
Enemy hand, deck order, cooldowns, future actions
Duration: 1-5 turns depending on skill
Effect: Perfect information for counterplay
Scales with Darshan stacks
```

**[Foreseen]** - Next action revealed, perfect counter enabled
```
Applied to enemy
You see their declared action before resolution
Can react with perfect counter
Duration: 1 turn typically
```

### Status Effects

**[Destiny Bound]** - Locked into predetermined outcome
```
Enemy must execute specific action/sequence
Duration: 3-4 turns
Cannot be changed except by [Cleanse]
Fate Thread mechanic
```

**[Temporal Echo]** - Action repeats automatically next turn
```
Applied to self or enemy
No cost for repeated action
Duration: 1-2 turn repeat
Can be positive (self buff) or negative (enemy locked in bad action)
```

**[Knowledge Drain]** - Abilities revealed and weakened
```
Enemy abilities visible + reduced potency (-50%)
Duration: 2-3 turns
Stacks with Darshan for additional weakening
```

**[Prophecy]** - Future event guaranteed to occur
```
Declared outcome WILL happen
Countdown: 2-5 turns typical
Cannot be prevented except by winning before trigger or [Cleanse]
Divination ultimate mechanic
```
