# MASTER HARMONIZATION FRAMEWORK v4.0
## Converting Skill Lists → Balanced v4.0 Engines

---

## 📋 PURPOSE

This framework provides the **systematic methodology** for integrating 100-skill engine lists into the v3.0 Master Game Design, creating harmonized v4.0 engines with:
- ✅ Perfect stat balance (TTK targets, control caps, cost curves)
- ✅ Canonical keyword consistency ([Burn], [Silence], [Charge], etc.)
- ✅ Cross-engine synergy integration (Architect's Codex)
- ✅ Jyotish gravitational hooks (planets, houses, nakshatras)
- ✅ Trinity meta alignment (Aggro • Control • Ramp)

## 🎯 CORE HARMONIZATION PRINCIPLES

### 1. RESOURCE UNIFICATION
**Problem:** Skill lists use unique resources (Ananda, Siddhi, Nirvana, Gnosis, etc.)
**Solution:** Map to Master v3.0 standard:
- **Primary:** KP (Knowledge Points) - universal tactical currency
- **Engine-Specific:** Threshold, Prana, Insight, Bandwidth, Coherence, Ojas, Sanctity, Threads
- **Conversion Formula:**
  - Ananda/Gnosis → Threshold (for Singularity)
  - Unique resources → Engine-specific resource + KP
  - Cost Range: 1-5 KP + 10-100 engine resource

### 2. KEYWORD CANONICALIZATION
**Problem:** Skill lists use varied terminology
**Solution:** Map to Master v3.0 keywords:

**Status Effects:**
- [Burn], [Decay], [Silence], [Stasis], [Banish], [Transcendent], [Seal], [Omen]

**Actions:**
- [Charge], [Threshold], [Collapse], [Invoke], [Chant], [Consecrate], [Foretell], [Analyze], [Mark], [Field], [Anchor], [Channel]

**Grammar:**
- Apply, Consume, Detonate, Bind, Transit, Seal, Chant

### 3. STAT BALANCE FRAMEWORK

#### Power Levels (Tier System)
**Tier 0 (Basic):** Foundational effects, always available
- Damage: 10-30
- Heal: 15-40
- Duration: 1-2 turns
- Cost: 1-2 KP + 10-30 engine resource

**Tier 1 (Standard):** Main deck workhorses
- Damage: 40-80
- Heal: 50-100
- Duration: 2-3 turns
- Cost: 2-3 KP + 30-60 engine resource
- Cooldown: 0-2

**Tier 2 (Advanced):** Powerful effects with conditions
- Damage: 100-150
- Heal: 120-200
- Duration: 3-4 turns
- Cost: 3-4 KP + 60-100 engine resource
- Cooldown: 2-4

**Tier 3 (Ultimate):** Game-changing effects
- Damage: 200-300
- Heal: 250-400
- Duration: 4-5 turns
- Cost: 4-5 KP + 80-120 engine resource
- Cooldown: 4-5

**Tier 4 (Apocalypse):** Win-condition effects
- Damage: 400+
- Heal: 500+
- Duration: 5+ turns or permanent
- Cost: 5 KP + 100-150 engine resource
- Cooldown: 5+ or once per duel

#### Cost Curve Formula
```
Base Cost = Tier × 1 KP
Engine Cost = (Tier × 20) + Complexity Modifier
Cooldown = Tier (0 for Tier 0, 1-2 for Tier 1, etc.)
```

**Complexity Modifiers:**
- Simple effect: +0
- Conditional effect: +10
- Multi-target/AoE: +20
- Cross-engine synergy: +15
- Reality-bending: +30

#### Balance Caps (from Master v3.0)
- **[Silence]:** ≤ 2 total turns in any 4-turn window
- **[Stasis]:** Stack cap varies by engine (2-5 max)
- **Damage caps:** Removed for specific "ceiling breaker" effects only
- **Healing overflow:** Converts to secondary benefits (Insight, Shield, etc.)
- **TTK Targets:** Aggro 3-5 turns, Midrange 5-7, Control 7-10

### 4. JYOTISH INTEGRATION

Every skill must have **gravitational hooks** for planetary/house influence:

**Planet Modifiers:**
- **Mars:** +30% [Burn] damage, +aggro effects
- **Saturn:** +duration, +[Stasis] effectiveness, +threshold rewards
- **Jupiter:** +AoE range, +expansion effects
- **Mercury:** -cooldowns, +tempo effects
- **Venus:** +healing, +[Cleanse] effects
- **Moon:** -ritual requirements (chant breakpoints), +intuition effects
- **Sun:** +authority effects, +damage
- **Rahu:** +chaos/variance, obsession bonuses
- **Ketu:** +liberation effects, void mechanics

**House Modifiers (Key Houses):**
- **House 6 (Enemies):** +debuff duration
- **House 8 (Transformation):** Ultimate cost -1
- **House 12 (Liberation):** +[Void]/[Banish] effects

**Nakshatra Examples:**
- **Pushya:** Shields regen Ojas
- **Purva Bhadrapada:** Duplicate [Channel] effects

### 5. CROSS-ENGINE SYNERGY SEEDS

Each skill should have **at least 1-2 cross-engine hooks** for Architect's Codex:

**Synergy Pattern Template:**
```
[Engine1 Keyword] + [Engine2 Keyword] → Enhanced Effect
```

**Examples:**
- Singularity [Charge] + Divination [Foretell] → Threshold gain on resolution
- Tantra [Burn] + Jyotish Mars → +30% [Burn] damage
- Invocation [Chant] + Moon → -1 chant requirement for breakpoint
- Consciousness [Field] + Jupiter → +radius expansion

### 6. EVOLUTION SYSTEM (from Skill Lists)

**Problem:** Skill lists have Evo A/Evo B branches
**Solution:** Integrate as **upgrade paths**:

**Standard Structure:**
- **Base Effect:** Core function (always available)
- **Upgrade A (Intensity):** +potency/damage/healing/duration
- **Upgrade B (Complexity):** New mechanics, cross-engine synergy, flexibility

**Upgrade Costs:**
- Upgrade A: +20-30% base cost
- Upgrade B: +40-50% base cost
- Both unlockable through: Jyotish mastery, Siddhi progression, or deckbuilding investment

## 🔧 HARMONIZATION WORKFLOW (7-Step Process)

### STEP 1: SKILL AUDIT
**Action:** Read skill list + v3.0 engine
**Output:** Spreadsheet with:
- Skill name
- Original cost/effect
- Power tier (0-4)
- Primary keyword(s)
- Cross-engine synergy potential
- Jyotish gravity hooks
- Conflicts/overlaps with v3.0

### STEP 2: RESOURCE MAPPING
**Action:** Convert unique resources to Master v3.0 standard
**Output:** Resource conversion table
```
Example (Singularity):
Ananda → Threshold
Siddhi → Permanent progression (like Invocation Presence)
Nirvana → Stack-based buff system
Gnosis → Cost currency (mapped to KP + Threshold)
```

### STEP 3: KEYWORD STANDARDIZATION
**Action:** Map skill effects to canonical keywords
**Output:** Keyword mapping table
```
Example:
"Shatter Ceiling" → [Threshold] mechanic + resource cap removal
"Transcendent" status → Use canonical [Transcendent] from Master v3.0
"Limit Breaking" → [Charge] mechanics + overflow handling
```

### STEP 4: STAT REBALANCING
**Action:** Apply cost curve formula, adjust damage/healing to tier system
**Output:** Balanced stat sheet with:
- KP cost (1-5)
- Engine resource cost (10-150)
- Cooldown (0-5+)
- Damage/heal values (tier-appropriate)
- Duration (tier-appropriate)

### STEP 5: GRAVITY HOOK INTEGRATION
**Action:** Add planet/house/nakshatra modifiers to each skill
**Output:** Gravity matrix per skill
```
Example:
Glyph: Reality Break
- Saturn: +1 turn duration
- Ketu: +bonus chaos effect
- House 8: Cost -20 Threshold
```

### STEP 6: SYNERGY SEED PLANTING
**Action:** Identify 2-3 cross-engine synergies per skill
**Output:** Architect's Codex entries
```
Example:
ACX-SING-DIV-03: Reality Break + Foretell
  → Rewritten reality sealed in future draw
```

### STEP 7: EVOLUTIONARY BRANCH DESIGN
**Action:** Create upgrade paths (Evo A/B from skill lists)
**Output:** Upgrade tree with clear progression

## 📝 NOTES & CONSIDERATIONS

**Power Creep Management:**
- Skill lists have god-tier effects (500% potency, reality breaking)
- v4.0 must preserve these as **aspirational peaks** but gate them appropriately
- Solution: Ultimate tier (Tier 4) with high costs, cooldowns, or duel limits

**Complexity Budget:**
- 100 skills per engine = high complexity
- Solution: Clear tier system, beginner/intermediate/advanced card pools
- New players start with Tier 0-1, advance to Tier 2-4

**Cross-Engine Balance:**
- Some engines (Invocation, Jyotish) already have 200+ skills
- Solution: Accept different skill counts, focus on play pattern balance

**Evolution System:**
- Evo A/B from skill lists = great depth
- Solution: Integrate as **masteries** or **aspect upgrades** in deckbuilding
