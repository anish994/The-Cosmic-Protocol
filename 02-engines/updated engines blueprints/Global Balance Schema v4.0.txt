# GLOBAL BALANCE SCHEMA v4.0
## The Rosetta Stone - Master Reference for All 9 Engines

---

## 📋 PURPOSE

This document is the **single source of truth** for balance across all 9 engines. Every stat, cost, keyword, and mechanic references this schema to ensure perfect harmony.

**Usage:** When designing/balancing any skill in any engine, reference the tables below to maintain consistency.

---

## 🎯 CORE BALANCE PHILOSOPHY

**The Three Laws of Balance:**
1. **Power should scale predictably** - Tier system ensures fair progression
2. **Every strength has a weakness** - Counterplay always exists
3. **Timing matters more than raw power** - Jyotish coordination beats brute force

**Design Targets:**
- **Aggro wins:** Turns 3-5 (fast pressure)
- **Midrange wins:** Turns 5-7 (balanced power)
- **Control wins:** Turns 7-10 (reactive dominance)
- **Ramp wins:** Turns 8-12 (explosive late-game)

### TIER SYSTEM (0-4)

All skills across all 9 engines follow this tier structure:

```
┌──────────┬──────────────┬───────────────┬──────────────┬──────────────┬──────────┐
│ TIER     │ DAMAGE       │ HEALING       │ DURATION     │ COST (KP)    │ COOLDOWN │
├──────────┼──────────────┼───────────────┼──────────────┼──────────────┼──────────┤
│ 0 Basic  │ 10-30        │ 15-40         │ 1-2 turns    │ 1            │ 0        │
│ 1 Standard│ 40-80       │ 50-100        │ 2-3 turns    │ 2            │ 0-2      │
│ 2 Advanced│ 100-150     │ 120-200       │ 3-4 turns    │ 3            │ 2-3      │
│ 3 Ultimate│ 200-300     │ 250-400       │ 4-5 turns    │ 4            │ 3-5      │
│ 4 Apocalypse│ 400-600+ │ 500-800+      │ 5+ or ∞      │ 5            │ 5+ or 1/duel│
└──────────┴──────────────┴───────────────┴──────────────┴──────────────┴──────────┘
```

### ENGINE RESOURCE COSTS (Secondary Costs)

```
┌──────────┬──────────────┬──────────────┬──────────────┬──────────────┬──────────┐
│ TIER     │ TIER 0       │ TIER 1       │ TIER 2       │ TIER 3       │ TIER 4   │
├──────────┼──────────────┼──────────────┼──────────────┼──────────────┼──────────┤
│ Simple   │ 10-20        │ 30-50        │ 60-80        │ 80-100       │ 100-120  │
│ Conditional│ 15-25      │ 40-60        │ 70-90        │ 90-110       │ 110-130  │
│ AoE/Multi │ 20-30       │ 50-70        │ 80-100       │ 100-120      │ 120-150  │
│ Cross-Engine│ 25-35     │ 55-75        │ 85-105       │ 105-125      │ 125-160  │
│ Reality-Bend│ 30-40     │ 60-80        │ 90-110       │ 110-130      │ 130-180  │
└──────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────┘
```

**Formula:**
```
Total Cost = KP Cost + Engine Resource Cost
Engine Resource = (Tier × 20) + Complexity Modifier
```

**Complexity Modifiers:**
- Simple effect (single target, straightforward): +0
- Conditional effect (requires setup): +10
- AoE/Multi-target: +20
- Cross-engine synergy: +15
- Reality-bending (breaks normal rules): +30

## 💰 RESOURCE CONVERSION MATRIX

### Primary Resources (All Engines)

**KP (Knowledge Points):** Universal tactical currency
- Starting: 3 KP
- Generation: +1 KP per turn
- Maximum: 10 KP
- Purpose: Gating powerful effects

### Legacy Resource Mapping (Skill Lists → Schema)

**Singularity Engine:**
- Ananda (skill list) → **Threshold** (schema)
- Siddhi (skill list) → **Mastery Levels** (permanent progression, +10% per level)
- Nirvana (skill list) → **[Transcendent] stacks** (buff system)
- Gnosis (skill list) → **KP + Threshold** (cost currency)

**Divination Engine:**
- Darshan → **Insight**
- Karma → **Karma Points** (permanent tracker)
- Temporal Threads → **Duration currency** (measured in turns)

**Tantra Engine:**
- Prana → **Prana** (kept as-is)
- Kundalini → **Kundalini Level** (0-10 permanent progression)
- Chakra Balance → **Dual resource** (tracks harmony/imbalance)

**Consciousness Engine:**
- Coherence → **Coherence** (kept as-is)
- Bandwidth → **Multi-target capacity** (3-7 max simultaneous effects)
- States → **Transformation enum** (Dormant/Active/Transcendent)

**All Other Engines:**
- Use Insight, Ojas, or Foundation as appropriate
- Secondary currencies map to stacks/counters

## 📐 COST FORMULA CALCULATOR

### Standard Cost Calculation

```python
def calculate_cost(tier, complexity, is_aoe=False, cross_engine=False, reality_bend=False):
    """
    Universal cost calculator for all engines
    
    Args:
        tier: 0-4 (power level)
        complexity: 'simple', 'conditional', 'aoe', 'cross', 'reality'
        is_aoe: Boolean (multi-target)
        cross_engine: Boolean (synergy with other engine)
        reality_bend: Boolean (breaks normal rules)
    
    Returns:
        dict: {'kp': int, 'engine_resource': int, 'cooldown': int}
    """
    
    # Base KP cost
    kp_cost = tier
    
    # Base engine resource cost
    base_resource = tier * 20
    
    # Complexity modifiers
    complexity_mod = {
        'simple': 0,
        'conditional': 10,
        'aoe': 20,
        'cross': 15,
        'reality': 30
    }
    
    engine_resource = base_resource + complexity_mod.get(complexity, 0)
    
    # Additional modifiers
    if is_aoe:
        engine_resource += 20
    if cross_engine:
        engine_resource += 15
    if reality_bend:
        engine_resource += 30
    
    # Cooldown (0 for Tier 0, scales with tier)
    cooldown = max(0, tier - 1) if tier < 3 else tier
    
    return {
        'kp': kp_cost,
        'engine_resource': engine_resource,
        'cooldown': cooldown
    }

# Examples:
# Tier 1 simple single-target = 2 KP + 40 engine resource, 0-2 CD
# Tier 2 AoE = 3 KP + 80 engine resource, 2-3 CD
# Tier 3 reality-bending cross-engine = 4 KP + 125 engine resource, 3-5 CD
# Tier 4 apocalypse = 5 KP + 150+ engine resource, 5+ CD or 1/duel
```

## 📊 BALANCE VALIDATION FORMULAS

### Expected Damage Per Turn (EDPT)

```
EDPT = (Base Damage × Hit Chance × Crit Multiplier) + (DoT × Duration)

Tier 0: 10-20 EDPT
Tier 1: 25-45 EDPT
Tier 2: 55-85 EDPT
Tier 3: 100-150 EDPT
Tier 4: 200+ EDPT (burst windows only)
```

### Resource Efficiency Ratio (RER)

```
RER = Total Effect Value / Total Cost

Good Value: RER > 1.2
Balanced: RER = 0.8-1.2
Overcosted: RER < 0.8

Effect Value = (Damage × 1.0) + (Healing × 0.8) + (Duration × 5) + (Utility × varies)
Total Cost = (KP × 20) + Engine Resource
```

### Win Rate Prediction Formula

```
Win Rate = Base Rate + Matchup Modifier + Skill Modifier + Jyotish Timing Modifier

Base Rate: 50% (mirrors)
Matchup Modifier: ±10-20% (archetype advantage)
Skill Modifier: ±5-15% (player expertise)
Jyotish Timing Modifier: ±5-10% (planetary alignment)

Target: All matchups should be 30-70% win rate (no auto-wins)
```
