## 💎 RESOURCE SYSTEM — UNIFIED SCHEMA

### Primary Resource: **Ojas Integrity**

**Concept:** Health/vitality metric that enables healing synergies  
**Range:** 0-100% (percentage of current Ojas / max Ojas)  
**Generation:** Gained through [Cleanse], shield uptime, safeguard effects  
**Purpose:** Unlock passive regeneration, amplify healing effects

**Legacy Mapping:**
```
Skill List v3.1    →    Schema v4.0
────────────────────────────────────
Ojas Integrity     →    Ojas Integrity % (0-100%)
Gnosis             →    KP + Ojas (cost split)
Sanctity           →    Sanctity (when hybridizing with Invocation)
```

**Key Resource Interactions:**
- **Ojas:** Spent to cast powerful heals, grant shields
- **Integrity:** Higher % unlocks bonus effects (milestones at 100%, 75%, 50%)
- **[Transmute]:** Convert incoming damage to healing or resources (refund 1 KP)
- **[Cleanse]:** Removes debuffs, grants +1 Ojas Integrity

### Secondary Resources

**Integrity Thresholds (Milestone Bonuses)**
- **100% Integrity:** All glyphs cost -1 KP, permanent 10 Shield
- **75%+ Integrity:** First [Shield] each turn doubled
- **50%+ Integrity:** [Cleanse] also [Heals] 5 Ojas
- **Below 50%:** Safeguard mode activated (emergency shields)

**Ojas Economy**
- **Starting Ojas:** 100 (standard)
- **Max Ojas:** 100 baseline (expandable with specific skills)
- **Healing Cap:** No single heal exceeds 50 Ojas baseline (prevents burst abuse)
- **Overheal:** Converts to temporary shields or resources (prevents waste)

## 🏷️ CANONICAL KEYWORD FRAMEWORK

### Core Action Keywords

**[Heal]** - Direct Ojas restoration
```
Restores X Ojas to target
First heal per turn: +10% potency (Moon)
Venus: Also [Cleanse] 1 debuff
Caps: Single heal max 50 Ojas baseline
```

**[Shield]** - Damage absorption barrier
```
Grants X Shield points (absorbs damage before Ojas loss)
Duration: Until broken or expires (3 turns typical)
Stacks: Can have multiple shields simultaneously
Pushya: Improves Ojas regeneration while active
```

**[Cleanse]** - Debuff removal
```
Removes 1 debuff from target
Grants +1% Ojas Integrity
Chaining: Can cascade to adjacent allies with specific skills
Venus: Automatic when [Heal] cast
```

**[Purify]** - Debuff conversion
```
Convert 1 debuff stack into [Shield]
Conversion Rate: 1 stack = 10 Shield baseline
Effect: Transforms enemy investment into defense
```

**[Transmute]** - Damage-to-resource conversion
```
Convert X incoming damage into Y healing or resources
Refund: 1 KP per transmutation
Conversion Rates: Varies by skill (25-75% typically)
Consciousness: Splash healing in [Field] radius
```

### Status Effects

**[Heal-over-Time (HoT)]** - Gradual restoration
```
Restores X Ojas per turn
Duration: 3-5 turns typically
Stacks: Multiple HoTs can be active simultaneously
Lifewell: +50% potency amplifier
```

**[Vulnerable]** - Increased damage taken
```
Target takes +25% damage
Duration: 1-2 turns typically
Counter: [Cleanse] removes immediately
Therapeutic: Can [Transmute] to reduce impact
```

**[Heal Block]** - Prevents healing
```
Target cannot receive [Heal] effects
Duration: 2-3 turns typically
Counter: [Cleanse], [Purify], or invocation blessing removal
```

**[Safeguard]** - Emergency protection
```
Automatic trigger when ally would die
Grants emergency shield (prevents death)
Cooldown: Once per 3 turns (prevents spam)
Cost: Spends Ojas Integrity
```

### Infinite Sustain Prevention

**Healing Caps:**
- Single heal max 50 Ojas baseline (prevents burst abuse)
- Ojas Integrity generation capped at +1% per [Cleanse]
- Overheal conversion has +50 max Ojas cap (prevents infinite scaling)

**Shield Caps:**
- Shield duration 3 turns typical (expires naturally)
- [Sunder] effects counter shields
- Shield stacking has diminishing returns

**Cleanse Caps:**
- [Cleanse] removes 1 debuff per cast (not all)
- Cooldowns prevent spam cleansing
- Immunity durations limited to 1-2 turns
