## 🎮 INTERACTION SYSTEM

### Power Scale Definitions

- **MINOR (1)**: Basic interactions (melting, cooling)
- **STANDARD (2)**: Common combinations (steam, mud)
- **MAJOR (3)**: Powerful effects (plasma, crystals)
- **EPIC (4)**: Rare combinations (void portals)
- **LEGENDARY (5)**: Ultimate fusions (reality breaks)

### Interaction Types

| Type | Meaning | Example |
|------|---------|---------|
| **SYNERGY** | Elements enhance each other | Fire + Lightning = Plasma Storm |
| **OPPOSITION** | Elements conflict/negate | Fire + Ice = Thermal Shock |
| **NEUTRAL** | Elements coexist | Water + Earth = Mud Slide |
| **CATALYTIC** | One enhances another | Metal + Fire = Molten Forge |
| **TRANSFORMATIVE** | Creates new effect | Fire + Water = Steam Vortex |

### Stability Ratings

- **UNSTABLE (0.5)**: Highly chaotic, hard to control
- **VOLATILE (0.8)**: Unpredictable but manageable
- **NEUTRAL (1.0)**: Standard stability
- **STABLE (1.2)**: Easy to control
- **PERFECT (1.5)**: Complete control

## 🔄 KEYWORD HIERARCHY SYSTEM

### Tag Structure (3-Level Hierarchy)

Each keyword has:
- **Primary Tag**: Main category (Damage, Control, Buff, etc.)
- **Sub-Tag**: Type classifier (DoT, CC, Healing, etc.)
- **Sub-Sub-Tag**: Specific effect (Burn, Stun, Regen, etc.)

### Example: Burn Keyword
```
Primary Tag: Damage
Sub-Tag: DoT (Damage over Time)
Sub-Sub-Tag: Fire (Fire element DoT)

Properties:
- Icon: 🔥
- Category: damage
- Color: #ff6464 (Red)
- Short: "Damage-over-time"
- Medium: "DoT that ticks fire damage over multiple turns"
- Strengths: ['Bypasses shields', 'Stacks over time', 'Area denial']
- Weaknesses: ['Can be cleansed', 'Slow to kill']
- Combos: ['Burn + Fire = Inferno', 'Burn + DoT stacking = Death']
```

## 🎯 FUSION RULES & BONUSES

### Tier Bonus System

Each interaction has a `tier_bonus` (1.4 - 3.2):
- **1.4 - 1.6**: Common, weak interactions
- **1.7 - 1.9**: Standard interactions
- **2.0 - 2.2**: Strong interactions
- **2.3 - 2.5**: Epic interactions
- **2.6 - 2.8**: Legendary interactions
- **2.9 - 3.2**: Ultimate/Cosmic interactions

### Duration Calculation
```
Duration = Power × Stability × Golden Ratio (φ)
```

### Area of Effect Calculation
```
AOE Radius = (Power × φ) × (Element Count × 0.5)
```
