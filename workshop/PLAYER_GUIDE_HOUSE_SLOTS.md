## 💡 Strategy Tips

### 1. Match Planets for Big Bonuses!
Look at the **planet icon color** in each house:
- **🔴 Mars (Red)** loves: Physical, Attack, Bleed skills
- **☀️ Sun (Gold)** loves: Power, AoE, Crit skills
- **🌙 Moon (Silver)** loves: Heal, Shield, Support skills
- **🟢 Mercury (Green)** loves: Speed, Combo, Quick skills
- **🟣 Jupiter (Purple)** loves: XP, Luck, Ultimate skills

**Pro Tip:** Matching 2+ tags = even bigger bonus!

### 2. Read the House Descriptions
Each house name hints at what skills work best:
- **Self** → Offensive, self-buff skills
- **Foundation** → Healing, defensive skills
- **Creativity** → High-power, flashy skills
- **Fortune** → XP gain, loot skills
- **Liberation** → Ultimate abilities

### 3. Look for the Glow!
- **Normal border** = Base bonus only
- **Colored glowing border** = Planet synergy active! (+15%+)
- **Teal highlight** = House synergy active! (+8%+)
- **BOTH glowing** = MAXIMUM POWER! (+23%+ combined!)

### 4. Experiment and Learn
The game teaches you naturally:
1. Place a skill
2. If it glows → Great match!
3. If not → Try a different house
4. Learn which skills match which planets
5. Optimize your build!

## ❓ FAQ

**Q: What does the checkmark ✓ badge mean?**  
A: It shows the slot is filled with a skill.

**Q: Why is my skill glowing?**  
A: It found a synergy! Check the bonus indicator at the bottom of the skill card.

**Q: Can I get both planet AND house synergy?**  
A: Yes! They stack multiplicatively for HUGE bonuses!

**Q: What's the Nakshatra info for?**  
A: It shows which lunar mansion the house is in. Currently informational, future updates may add bonuses!

**Q: How do I know if a skill will synergize before placing it?**  
A: Look at the skill's tags and compare to:
  1. The planet icon color (hover for planet name)
  2. The house name/description

**Q: Can I move skills between houses?**  
A: Yes! Click the × button to remove, then place it in a new house.
