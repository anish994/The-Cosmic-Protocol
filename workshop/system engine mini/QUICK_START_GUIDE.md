## 🚀 How to Use

### 1. Open the File
Open `02-keywords-matrix-engine.html` in any modern browser

### 2. Click "Open Fusion Workshop"
Button appears in the header

### 3. Select Keywords (up to 10)
Click any keyword card - it will show a checkmark

### 4. Choose Element (optional)
Click an element icon in the workshop panel

### 5. Calculate Fusion
Click "⚡ Calculate Fusion" to see results

### 6. Save or Export
- Save fusion to library
- Sync with elemental engine
- Clear and start over
