## 🎯 CORE PHILOSOPHY

**"Total Freedom to Create, Discover, and Transcend"**

The Fusion System allows players to combine ANY skills (base or fused) to create new, unique abilities. Through experimentation and mastery, players can discover infinite combinations, eventually leading to the legendary **OM skills** - the ultimate transcendent abilities.

---

## 🔮 FUSION SCOPE

### **Complete Freedom:**
- ✅ **Same-Engine Fusion:** Combine skills from one engine (e.g., Foundational + Foundational)
- ✅ **Cross-Engine Fusion:** Combine skills from different engines (e.g., Foundational + Singularity)
- ✅ **Hybrid Fusion:** Mix base skills with already-fused skills
- ✅ **Recursive Fusion:** Fuse fused skills infinitely (no depth limit until OM)

### **Smart Synergy:**
Cross-engine fusions automatically detect thematic connections and create emergent properties based on engine interactions.

**Example:**
- Foundational + Therapeutic = Healing structures
- Singularity + Tantra = Reality-warping decay
- Divination + Consciousness = Predictive mental fields

## ⚙️ FUSION MECHANICS

### **Fusion Input:**
- **Minimum:** 2 skills
- **Maximum:** 8 skills
- **Any combination** of base skills, fused skills, or mix

### **Fusion Output:**
- **One new fused skill** with properties synthesized from all ingredients
- **Fusion Depth:** Tracks how many times this skill lineage has been fused
- **Genealogy:** Complete record of all ingredient skills used

### **Fusion Depth System:**

```
Depth 0: Base skills (from your 1000+ blueprints)
Depth 1: First fusion (combining base skills)
Depth 2: Second fusion (combining depth 1 skills or depth 1 + base)
Depth 3: Third fusion (and so on...)
Depth ∞: Theoretically unlimited...
Depth OM: Final form - cannot be fused further
```

## 🧬 FUSION ALGORITHM COMPONENTS

### **What Determines Fusion Results:**

1. **Keyword Synthesis:**
   - Extract tags/keywords from all ingredient skills
   - Detect dominant patterns (50%+ frequency)
   - Generate emergent keywords for cross-engine combos
   - Example: [Shield] + [Burn] = [Adaptive]

2. **Effect Blending:**
   - Merge mechanical effects intelligently
   - Preserve core identity from strongest ingredient
   - Add complementary effects from others
   - Create new effects when synergy detected

3. **Resource Calculation:**
   - KP cost = weighted average of ingredients
   - Scales with fusion depth (+10% per depth level)
   - Cross-engine fusion slight premium (+20%)

4. **Power Scaling:**
   - Base power = average of ingredients
   - Synergy bonus = up to +50% for perfect matches
   - Depth bonus = +10% per fusion depth level
   - Diminishing returns after depth 5

5. **Name Generation:**
   - Dynamic name based on dominant themes
   - Power words from highest-tier ingredient
   - Descriptive action/noun from effect blend
   - Cross-engine fusions get "Unity/Convergence/Fusion" themes

6. **Cosmic DNA Assignment:**
   - Ruling planet = most common among ingredients
   - House affinity = weighted average
   - Nakshatra = inherited from primary ingredient
   - Jyotish properties affect power scaling

7. **Engine Classification:**
   - Same-engine fusion = that engine
   - Cross-engine fusion = "Multi" or "Hybrid"
   - 3+ engines = "Convergence"
   - All 7+ engines = "Transcendent"
