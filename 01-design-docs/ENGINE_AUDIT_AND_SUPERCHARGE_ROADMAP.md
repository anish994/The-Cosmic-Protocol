# Engine Audit & Supercharge Roadmap

## Purpose
Assess the current state of all 9 game engines by comparing original blueprints to v3.0 updates, count concrete skills/entities, and identify which engines need massive skill roster expansions to compete with the depth of Invocation Engine and major CCGs like Magic: The Gathering, Gwent, and Hearthstone.

---

## Engine-by-Engine Analysis

### 1. **Invocation Engine**

**Original State (engines txt/):**
- Comprehensive pantheon descriptions (angels, demons, deities)
- Rich lore and thematic identity
- Estimated: ~50-80 concrete entity concepts

**v3.0 State (updated engines blueprints/):**
- Fully structured with executive summary, canonical keywords, resource models
- **Concrete Skills Created:** 247 fully-defined Glyphs
  - 79 Angels (complete Shem HaMephorash + 7 Archangels)
  - 72 Demons (complete Ars Goetia)
  - 96 Divine Pantheon entities (Vedic 38, Norse 28, Egyptian 30)
- Complete JSON manifestation in `invocation_pantheon_v3.json`
- Each entity has: ID, name, cost, keywords, effect, resonance requirements, Jyotish gravity modifiers, lore

**Status:** ✅ **LEGENDARY-TIER COMPLETE**  
**Depth Score:** 10/10 (247 unique, fully-designed Glyphs with deep mechanical identity)

## Initial Findings

### The Gap
- **Invocation Engine:** 247 fully-designed Glyphs (LEGENDARY)
- **Tantra Engine:** ~20 foundational Glyphs (MECHANICS BRILLIANT, ROSTER SHALLOW)
- **Other 6 Skill Engines:** Status unknown, likely similar to Tantra

### The Supercharge Plan

To compete with Magic: The Gathering (20,000+ cards), Gwent (1,000+ cards), and Hearthstone (2,500+ cards), we need:

**Target Skill Count Per Engine:** 150-250 fully-designed Glyphs  
**Total Game Skill Pool Target:** 1,200-2,000 Glyphs across 8 engines

**Methodology:**
1. **Audit Phase (Current):** Read and analyze all 8 skill engines to count existing concrete skills
2. **Gap Analysis:** Identify which engines need the most work
3. **Design Sprint:** Systematically expand each shallow engine using the Invocation Engine's JSON format as a template
4. **Balance Pass:** Ensure cross-engine synergies (Codex hooks, Jyotish gravity) are consistent
